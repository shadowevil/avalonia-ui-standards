# 0023 — Versioning

- **Status:** Agreed, 2026-11-12
- **Decision:**
  - The library uses semantic versioning. It starts at 0.1.0 while the API is still changing, and reaches 1.0.0 once the tiers are stable.
  - The version is set in the library project.
- **Why:** Apps can tell compatible updates from breaking ones.

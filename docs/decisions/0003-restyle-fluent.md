# 0003 — Restyle Fluent, not a theme from scratch

- **Status:** Agreed, 2026-11-12
- **Decision:** A control Fluent provides is restyled, not rewritten. New templates are written only for controls Fluent lacks (for example Dialog). The look comes from the values in the Style tier.
- **Why:** It keeps Fluent's accessibility and keyboard behaviour while the Style tier defines the look.

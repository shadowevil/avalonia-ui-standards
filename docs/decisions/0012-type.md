# 0012 — Type

- **Status:** Agreed, 2026-11-12
- **Decision:**
  - The typeface is Inter, bundled through `Avalonia.Fonts.Inter` (pinned with Avalonia, [0008](0008-target-versions.md)).
  - The type ramp follows the Windows 11 ramp (sizes in px):

    | Style | Size | Weight |
    |---|---|---|
    | Caption | 12 | regular |
    | Body | 14 | regular |
    | Body strong | 14 | semibold |
    | Subtitle | 20 | semibold |
    | Title | 28 | semibold |
    | Large title | 40 | semibold |
    | Display | 68 | semibold |

  - Each semibold step has a weight key: `FontWeightBodyStrong`, `FontWeightSubtitle`, `FontWeightTitle`, `FontWeightLargeTitle`, `FontWeightDisplay`.
- **Why:** Text is identical on every OS and in headless renders. Body 14 matches Fluent's control text.

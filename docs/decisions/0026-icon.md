# 0026 — Icon

- **Status:** Agreed, 2026-11-13
- **Decision:**
  - The icon set is Phosphor, Regular weight (MIT). Its licence and source are in `THIRD-PARTY-NOTICES.md` at the repo root, which the library's NuGet package includes at its root.
    - **Why:** One consistent vector set with outlined fill paths, under a licence that allows shipping it inside the library.
  - `Icon` is a Block ([0004](0004-tier-names.md)): a subclass of Fluent's `PathIcon`, so it goes wherever a `PathIcon` does, with its own control theme.
    - **Why:** It keeps Fluent's icon element and its uses ([0003](0003-restyle-fluent.md)) and changes only how the geometry is fitted.
  - The theme keeps the 256 × 256 design box: a `Viewbox` over a fixed 256 × 256 canvas holding the path with `Stretch=None`.
    - **Why:** Fluent's `PathIcon` template stretches each geometry's own bounds to the icon's size, so small glyphs (caret-down) would blow up and icons would differ in size and position. In the design box every icon keeps the proportions and placement it was drawn with.
  - Sizes: 20 px at Normal density and 16 px at Compact ([0013](0013-spacing-and-density.md)); 24 px for larger use, set through `Width` and `Height`. Phosphor Regular's stroke is 16/256 of the box, so it is 1 px at 16, 1.25 px at 20, 1.5 px at 24 and 2 px at 32.
    - **Why:** 16, 20 and 24 are the common desktop icon sizes (Fluent System Icons ship in them), the stroke stays near 1 px at the two density sizes, and the smaller size fits Compact's 24 px controls.
  - The colour is the inherited `Foreground`; the theme sets none. An icon takes the text colour of the control it sits in, and a disabled control dims it as it dims its text.
    - **Why:** Icons follow every state colour of their host (accent, destructive, selected, disabled) with no state styles of their own.
  - Only the `Icon` type gets this theme. Plain `PathIcon` keeps Fluent's theme, and Fluent's own internal glyphs stay until each Block replaces them.
    - **Why:** Restyling every `PathIcon` would change Fluent's glyphs, drawn for its stretch-to-bounds template, in controls not yet restyled ([0007](0007-restyle-scope.md)).
  - The geometries are the static class `Icons`, one `Geometry` property per icon, named after the Phosphor name in Pascal case (`caret-down` is `Icons.CaretDown`). Each holds the SVG's `d` attribute verbatim; it is parsed with `F1` prefixed, on first use, and shared.
    - **Why:** Typed names that work from code and from XAML (`{x:Static Icons.CaretDown}`). `F1` selects the nonzero fill rule SVG uses; Avalonia's path markup defaults to even-odd.
  - Only icons that the library's Blocks or the catalog need, now or in the remaining M3 steps, are shipped. The starting set covers the remaining M3 Blocks and the catalog: app-window, arrows-out-line-horizontal, bell, calendar, calendar-blank, caret-down, caret-left, caret-right, caret-up, chat-text, check, check-circle, check-square, clock, cursor-click, dots-three, drop, eye, eye-slash, frame-corners, gear, house, info, intersect-square, list, list-bullets, magnifying-glass, minus, palette, play, plus, radio-button, ruler, selection, sidebar-simple, sliders-horizontal, square, squares-four, subtract-square, tabs, text-aa, toggle-right, tree-structure, unite-square, warning, warning-circle, x, x-circle.
    - **Why:** The package carries no glyph without a planned use. The four selection-mode icons (`square`, `unite-square`, `subtract-square`, `intersect-square`) are for the selection modes of a segmented control: New, Add, Subtract and Intersect ([0032](0032-segmented-control.md)). The selection-style icons `selection` and `frame-corners` are for the selection style of a segmented control, Normal and Fixed ratio; Fixed size uses `ruler`.
  - The library also has its own icons, drawn in Phosphor Regular's style where Phosphor has no glyph for a meaning: 16-wide strokes with round caps and joins on the 256 grid, stored as the fill outlines of those strokes (path data used verbatim with `F1`, like the Phosphor ones). They are named for their meaning, not after a Phosphor name, so they never clash with one. Icons derived from Phosphor's artwork are covered by its MIT licence in `THIRD-PARTY-NOTICES.md`, which names them.
    - The motion icons are `MotionReduced`, `MotionSystem` and `MotionFull`: Phosphor's person-simple-run figure (its strokes traced from Phosphor's outline and redrawn at 0.8 of its size with the full 16-wide stroke, at the right edge and the top of the box, its ink from y 24 as in Phosphor) with wind trails behind it in the style of Phosphor's `wind` (a straight line ending in a curl): one curl for reduced motion (between the arm and the trailing leg), two for motion that follows the OS (above the arm and below the trailing foot), and three gusts (those curls with a long straight line between them) for full motion; curls have a 16 radius. Every glyph spans x 20 to 240.
    - **Why:** The icon shows the selected value of the motion setting, and drawing in Phosphor's stroke, caps and grid keeps the library's icons one set.
  - Adding an icon: copy the `d` attribute of `assets/regular/<name>.svg` from the Phosphor repo into a new `Icons` property with the Pascal-case name. There is no generator for `Icons.cs`; the web copy is generated from it (see Web).
    - **Why:** The set is small and curated, and each addition is one reviewed line.
  - Web ([0045](0045-web-library.md)): an inline `<svg class="ui-icon">`, decorative (`aria-hidden`) unless given a label, built by `icon(name, {label, size})`. `web/blocks/icons.js` is generated from `Icons.cs` by `web/tools/icons.py`, whose `--check` fails when the two differ, so an icon is still added only in `Icons.cs`.

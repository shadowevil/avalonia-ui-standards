# 0026 — Icon

- **Status:** Agreed, 2026-11-13
- **Decision:**
  - The icon set is Phosphor, Regular weight (MIT). Its licence and source are in `THIRD-PARTY-NOTICES.md` at the repo root, which the library's NuGet package includes at its root.
    - **Why:** One consistent vector set with outlined fill paths, under a licence that allows shipping it inside the library.
  - `Icon` is a Block ([0004](0004-tier-names.md)): a subclass of Fluent's `PathIcon`, so it goes wherever a `PathIcon` does, with its own control theme.
    - **Why:** It keeps Fluent's icon element and its uses ([0003](0003-restyle-fluent.md)) and changes only how the geometry is fitted.
  - The theme keeps the 256 × 256 design box: a `Viewbox` over a fixed 256 × 256 canvas holding the path with `Stretch=None`.
    - **Why:** Fluent's `PathIcon` template stretches each geometry's own bounds to the icon's size, so small glyphs (caret-down) would blow up and icons would differ in size and position. In the design box every icon keeps the proportions and placement it was drawn with.
  - Sizes: 20 px at Normal density and 16 px at Compact ([0013](0013-spacing-and-density.md)); 24 px for larger use, set through `Width` and `Height`. Phosphor Regular's stroke is 16/256 of the box, so it is 1 px at 16, 1.25 px at 20, 1.5 px at 24 and 2 px at 32.
    - **Why:** 16, 20 and 24 are the common desktop icon sizes (Fluent System Icons ship in them), the stroke stays near 1 px at the two density sizes, and the smaller size fits Compact's 24 px controls.
  - The colour is the inherited `Foreground`; the theme sets none. An icon takes the text colour of the control it sits in, and a disabled control dims it as it dims its text.
    - **Why:** Icons follow every state colour of their host (accent, destructive, selected, disabled) with no state styles of their own.
  - Only the `Icon` type gets this theme. Plain `PathIcon` keeps Fluent's theme, and Fluent's own internal glyphs stay until each Block replaces them.
    - **Why:** Restyling every `PathIcon` would change Fluent's glyphs, drawn for its stretch-to-bounds template, in controls not yet restyled ([0007](0007-restyle-scope.md)).
  - The geometries are the static class `Icons`, one `Geometry` property per icon, named after the Phosphor name in Pascal case (`caret-down` is `Icons.CaretDown`). Each holds the SVG's `d` attribute verbatim; it is parsed with `F1` prefixed, on first use, and shared.
    - **Why:** Typed names that work from code and from XAML (`{x:Static Icons.CaretDown}`). `F1` selects the nonzero fill rule SVG uses; Avalonia's path markup defaults to even-odd.
  - Only icons that the library's Blocks or the catalog need, now or in the remaining M3 steps, are shipped. The starting set covers the remaining M3 Blocks and the catalog: arrows-out-line-horizontal, bell, calendar, calendar-blank, caret-down, caret-left, caret-right, caret-up, chat-text, check, check-circle, check-square, clock, cursor-click, dots-three, drop, eye, eye-slash, gear, house, info, list, list-bullets, magnifying-glass, minus, palette, play, plus, radio-button, ruler, sidebar-simple, sliders-horizontal, squares-four, tabs, text-aa, toggle-right, tree-structure, warning, warning-circle, x, x-circle.
    - **Why:** The package carries no glyph without a planned use.
  - Adding an icon: copy the `d` attribute of `assets/regular/<name>.svg` from the Phosphor repo into a new `Icons` property with the Pascal-case name. There is no generator.
    - **Why:** The set is small and curated, and each addition is one reviewed line.

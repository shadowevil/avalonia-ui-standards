# 0002 — Desktop first, web decided later

- **Status:** Agreed, 2026-11-12
- **Decision:** Build the desktop library first. The web decision is due once each of the four tiers has its first agreed contents: Style values, Blocks and Modules controls, and a Screen. The options are Avalonia WASM or a separate web stack; how web relates to the Style tier is part of that decision.
- **Why:** The web options are judged on merit once the desktop library has substance, not guessed up front.

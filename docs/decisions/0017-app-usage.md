# 0017 — How apps use the library

- **Status:** Agreed, 2026-11-12
- **Decision:**
  - Apps replace `<FluentTheme/>` with `<StandardsTheme/>` and call `.UseUiStandards()` on the `AppBuilder`, which registers Inter ([0012](0012-type.md)) and sets Skia's GPU resource budget to 256 MB (`AppBuilderExtensions.GpuResourceBudget`, [0015](0015-glass.md)). An app sets its own budget, or other Skia options, with `.With(new SkiaOptions { ... })` after `.UseUiStandards()`. That call replaces the whole `SkiaOptions`, so an app that sets other options and keeps the budget includes `MaxGpuResourceSizeBytes = AppBuilderExtensions.GpuResourceBudget`.
  - Style tier resource keys use plain names in the style of Avalonia's own keys, for example `FontSizeBody`, `SpacingM`, `CornerRadiusControl`, `MotionFast`.
  - Key families: `FontSize*`, `FontWeight*`, `Spacing*` (each step as a `double`, `…Thickness` and `…GridLength`, [0013](0013-spacing-and-density.md)), `CornerRadius*`, `CornerSmoothing`, `Motion*`, `Glass*`, `BackdropWash*`, `AccentFill*`, `AccentText*`, `DangerColor*`, `DangerFill*`, `DangerForeground`, `DangerTextColor`, `Success*`, `Warning*` (the last three in [0037](0037-tooltip-and-notifications.md)).
  - The string resources `ColorView*Text` and `ColorView*Letter` hold the ColorView's shown and spoken strings with English defaults; an app overrides one by putting its key in its own resources ([0041](0041-colorpicker.md)). `SidebarFooterText` names the Sidebar's footer list for assistive technology, overridden the same way ([0034](0034-sidebar.md)). `MenuRowHelpHeader` (default `_Help`) is the Help menu's header that the menu row finds and adds the application menu's items to, overridden the same way ([0044](0044-menu-bar.md)). `StatusBarText` (default "Status") names the status bar and `StatusBarCancelText` (default "Cancel") its progress items' cancel button, overridden the same way ([0047](0047-status-bar.md)).
  - App windows subclass `StandardsWindow` ([0022](0022-window-layout.md)), which has a public `Backdrop` content slot (empty by default).
  - The attached property `ScrollShadows.IsEnabled` turns the scroll-edge shadow off per scroller ([0024](0024-lists-and-scrolling.md)).
  - The attached properties `TreeViewOptions.ExpandOn` and `TreeViewOptions.CollapseOn` (`TreeViewClickAction`) set which row clicks expand and collapse a tree's items, and `TreeViewOptions.ShowLines` (default true) shows its node lines, per tree or per item ([0035](0035-treeview.md)).
  - The attached property `SelectionOptions.AccentFlag` (default false) shows the accent flag on the selected items of a ListBox, Sidebar, ComboBox, AutoCompleteBox or TreeView, per list or per item ([0042](0042-accent-flag.md)).
  - `StandardsWindow.FrameTick` (with `FrameTickEventArgs`) and `StandardsWindow.HighRefreshRate` pace continuous animation ([0016](0016-motion.md)).
  - `StandardsWindow.ContentPanelBounds` (read-only) is the glass panel's rectangle in the `Backdrop` slot's coordinates ([0022](0022-window-layout.md)).
  - `StandardsWindow.IsContentScrollable` (default true) makes the glass panel scroll its content ([0022](0022-window-layout.md)).
  - `StandardsWindow.LayoutMode` (a `WindowLayoutMode`: `Automatic`, `MacOS`, `Windows`) sets which OS's window layout the window shows ([0022](0022-window-layout.md)).
  - Menus are Avalonia's `NativeMenu`, set on the window (`NativeMenu.Menu`) and on the `Application` for the application menu; in the Windows layout `StandardsWindow` shows the window's menu in its menu row ([0044](0044-menu-bar.md)).
  - `StandardsWindow.ResolvedLayoutMode` (read-only) is the layout in use ([0022](0022-window-layout.md)).
  - `StandardsWindow.ToggleFullScreen()` enters or leaves full screen on macOS, and `FullScreenMenuItem` is the View menu's full screen item; the string resources `FullScreenEnterHeader` and `FullScreenExitHeader` hold its headers, overridden as above. `WindowButtons` has `CanMinimize`, `CanMaximize`, `IsFullScreenAvailable` and `IsFullScreen`, and `WindowButtonKind.FullScreen` ([0049](0049-full-screen.md)).
  - `StandardsWindow.ToolbarBand` holds a `ToolbarBand`, whose items take the attached properties `ToolbarBand.Zone` (a `ToolbarZone`), `Priority`, `Label`, `CanOverflow` and `BeginsGroup`; `ToolbarSpacer` is its flexible space ([0043](0043-toolbar-band.md)).
  - `StandardsWindow.StatusBar` holds a `StatusBar` with a `Message`, whose items take the attached properties `StatusBar.Zone` (a `StatusZone`), `Priority` and `ShortTexts`; `StatusProgress` is its progress item (`Value`, `IsIndeterminate`, `Text`, `Kind` as a `StatusProgressKind`, `IsCancelable` and `CancelRequested`) ([0047](0047-status-bar.md)).
  - `StandardsTheme` properties: `Accent`, `Density`, `ReduceMotion`, `ReduceTransparency`, `HighRefreshRate`, `GlassQuality`.
  - `StandardsTheme.CreateForTests(AccessibilitySettings)` creates the theme with the OS reduce-motion and reduce-transparency settings pinned (`AccessibilitySettings.NotReduced` for neither), so an app's headless tests do not depend on the machine. Apps use the constructor, which reads the OS.
  - `StandardsWindow.TitleIconDecoderForTests` (a `Func<WindowIcon, IImage?>`, null by default) is for headless tests only: it turns `Window.Icon` into the title icon's image, since headless window icons hold no image data, so an app's tests can render the Windows layout's title icon ([0022](0022-window-layout.md)). It is set per window, because app windows are subclasses and tests stay independent of each other; apps leave it null.
  - `GlassQuality` (`Full`, the default; `Minimal`; `Solid`) sets how glass draws app-wide; see [0015](0015-glass.md).
  - Web ([0045](0045-web-library.md)): a page loads `web/ui.css` and `web/ui.js`. The stylesheet also styles `body` (Inter, primary text, page background), as the desktop theme styles the whole window. `ui.js` exports `setTheme`, `setAccent`, `setDensity`, `setReduceMotion` and `setReduceTransparency`, which set the theme attributes of [0046](0046-web-browsers-markup-naming.md) and recompute the accent-derived values for both themes.
- **Why:** Adopting the library takes one line, and the keys read like Avalonia's.
